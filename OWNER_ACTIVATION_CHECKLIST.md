# OWNER ACTIVATION CHECKLIST

## Before taking public payments

- [ ] Verify the revenue wallet in `config.js`
- [ ] Add a support email
- [ ] Register the operating business/name
- [ ] Obtain an EIN if appropriate
- [ ] Open a separate business bank account
- [ ] Record all crypto and fiat income for taxes
- [ ] Have the Terms, Privacy, Fees, Risk, and Refund pages reviewed
- [ ] Confirm whether Arizona or other state licensing applies
- [ ] Do not custody customer fiat or crypto

## Swap revenue

- [ ] Create thirdweb project
- [ ] Add client ID to `config.js`
- [ ] Set 1.25% developer fee in dashboard
- [ ] Set correct fee recipient
- [ ] Test a small swap
- [ ] Confirm revenue arrives
- [ ] Confirm public fee disclosure matches dashboard

## Card revenue

- [ ] Apply to MoonPay/Transak
- [ ] Complete KYB
- [ ] Obtain production credentials
- [ ] Confirm supported partner fee in writing
- [ ] Confirm refund/chargeback responsibility
- [ ] Confirm supported states/countries
- [ ] Turn on public partner-fee disclosure only after approval

## Affiliate revenue

- [ ] Apply to Coinbase affiliate program
- [ ] Add tracked URL
- [ ] Keep affiliate disclosure visible
- [ ] Track conversions and payouts

## FlowGate Plus

- [ ] Make a test purchase
- [ ] Confirm 9.99 USDC reaches the correct wallet
- [ ] Verify the toolkit unlocks
- [ ] Add backend verification before scaling

## White-label sales

- [ ] Add support email
- [ ] Prepare written scope template
- [ ] Prepare invoice/payment terms
- [ ] Define delivery milestones
- [ ] Define post-delivery support
- [ ] Never accept custom-work payment before the scope is signed


## Master attribution

- [ ] Confirm `ownerCampaignId` and `ownerReferralCode`
- [ ] Keep one owner-controlled thirdweb project across every hosted copy
- [ ] Replace all generic provider links with approved tracked links
- [ ] Use partner-generated or securely signed widget URLs where required
- [ ] Test that provider dashboards attribute real transactions correctly
- [ ] Keep “Powered by FlowGate” and fee disclosures visible
- [ ] Use a hosted-license agreement instead of transferring unrestricted source code
- [ ] Bill setup and monthly license through a proper invoicing/subscription system
- [ ] Never advertise commissions as permanent or guaranteed


## Digital-product purchase setup

- [ ] Create an approved merchant account for FlowGate Plus
- [ ] Describe the product accurately as digital software
- [ ] Request the recognizable descriptor `FLOWGATE DIGITAL`
- [ ] Confirm the merchant category with the processor
- [ ] Keep crypto on-ramp purchases separate and provider-controlled
- [ ] Test the statement descriptor with a small real product purchase
- [ ] Never disguise crypto as unrelated merchandise
