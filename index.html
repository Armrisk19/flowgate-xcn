3 steps

Card route through Ethereum

Buy Ethereum USDC with an available card provider, swap that USDC to Ethereum XCN, then bridge XCN to Onyx.

01
Card purchase

Buy USDC on Ethereum

Connect the wallet that will receive the USDC. In the widget, select Card as the payment method and confirm the receiving token says USDC on Ethereum.

Credit-card acceptance depends on the on-ramp provider and your card issuer. Debit cards are usually more widely supported.
Card → Ethereum USDC
02
Onyx Swap

Swap Ethereum USDC to XCN

  1. Open the official Onyx Swap.
  2. Select the Ethereum network tab.
  3. Set From: USDC.
  4. Set To: XCN.
  5. Review the quote, network fee, and minimum received.

03
Official bridge

Bridge XCN from Ethereum to Onyx

  1. Open the official Onyx Bridge.
  2. Set From: Ethereum.
  3. Set To: Onyx.
  4. Select XCN.
  5. Connect the same wallet and bridge a small test amount first.
